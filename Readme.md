# NYC Civil Service Title Finder

A client-side, zero-dependency single-page application (SPA) designed to help candidates, employees, and HR analysts discover NYC Civil Service titles based on task descriptions, jurisdictional classes, bargaining units, and job requirements.

## Features

- **Keyword & Task Search:** Search across duties, job descriptions, and qualification requirements.
- **Multi-Faceted Filtering:**
  - HR Search Categories / Type of Work (Benefits, IT, Analytics, Clerical, etc.)
  - Jurisdictional Class (Competitive, Non-Competitive, etc.)
  - Specification Levels (Level I through Level IV)
  - Bargaining Unit (DC37, CWA, OSA, N/U, etc.)
  - Standard Hours (35 vs 40 hours)
  - Direct Title or Title Code lookup
- **Detailed Specification Modal:** View full official specification text, education and experience minimums, direct lines of promotion, and assignment-level salary bands.
- **Side Panel Explorer:** Category breakdown counts and fast search for quick browsing.
- **Zero Dependencies:** Pure HTML, CSS, and vanilla JavaScript—runs instantly in any browser without build tools or web servers.
